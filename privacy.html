ANUBIS Privacy Policy

Last updated: 3 October 2026

ANUBIS is a personal assistant used only by its owner. This policy describes how it handles Google user data.

Data accessed

With the owner's consent, ANUBIS requests read-only access to Google Calendar (calendar.readonly) for the owner's own account. It cannot create, change or delete calendar data.

How data is used

Calendar events are used only to send the owner reminders, daily agendas and meeting-preparation notes. Event details may be sent to an AI model provider (Anthropic) solely to write those notes for the owner.

Storage and sharing

Data is stored on the owner's own computer or server, and event data is deleted automatically after the event has passed. It is not sold, shared with third parties for any other purpose, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
